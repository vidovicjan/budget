# Budget Tracker for Android

The phone version of Budget Tracker, built with [Capacitor](https://capacitorjs.com). It runs
the same app code as the desktop app (`../src`) inside an Android WebView, so features stay
in sync automatically. Only the phone frame lives here:

| File | What it does |
| --- | --- |
| `src/main.tsx` | Entry point: loads the shared app inside the phone shell |
| `src/MobileShell.tsx` | Top bar, slide-in menu, Android back button |
| `src/platform.ts` | Saving files (share sheet), opening files, live price requests |
| `src/mobile.css` | Phone layout on top of the shared styles |
| `android/` | The Android Studio project (generated by Capacitor, safe to commit) |

Data is stored on the phone (IndexedDB inside the app), the same way as on desktop.
Backups exported on desktop can be imported on the phone and the other way round.

## One-time setup

1. Install **Android Studio** (it includes the Android SDK and Java 21).
2. In this folder run `npm install` (the main folder needs `npm install` too).

## Everyday commands (run in `mobile/`)

| Command | What it does |
| --- | --- |
| `npm run dev` | Preview in the browser at http://127.0.0.1:5174 (shrink the window or use the phone view in DevTools) |
| `npm run sync` | Build and copy the app into `android/` — run after every code change |
| `npm run open` | Open the project in Android Studio (press Run ▶ to start it on a phone or emulator) |
| `npm run android` | Build, sync and run on a connected phone or emulator |
| `npm run apk` | Build a debug APK: `android/app/build/outputs/apk/debug/app-debug.apk` |

To install on your own phone: turn on **Developer options → USB debugging**, plug it in and run
`npm run android`, or copy `app-debug.apk` to the phone and open it.

## Releasing

- Bump `versionCode` (by 1) and `versionName` in `android/app/build.gradle`.
- For the Play Store build a signed **App Bundle** in Android Studio (Build → Generate Signed App Bundle).
  Keep the keystore file and its passwords safe — every update must be signed with the same key.
- The app id `com.budgettracker.app` can't change once the app is published.
